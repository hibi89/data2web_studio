# A25-02 — 운영자 사본 custody·보유·반환·파기 기록 서식

**상태: 빈 내부 서식만 제공. 실제 고객 기록·보유 통지·파기 증거가 아니며 R25 수용이나 점수에 반영되지 않음.**

고객별로 비공개·접근 통제된 기록에 작성한다. 이 공개 서식에는 고객 이름, 주문번호, 파일명, 실제 경로, 데이터 값, 개인 경로, 서명 또는 증빙을 채우지 않는다. 각 사본 객체마다 별도 행을 만들고, 고객 원본과 결과물을 하나의 보유기간으로 묶지 않는다.

## 1. 사본 기록

| 항목 | 비공개 기록에 기입 |
|---|---|
| 익명 내부 참조 | 고객 식별자가 아닌 임의 참조 ID |
| 기록 유형 | ☐ 운영자 원본 사본 ☐ 운영자 결과 사본 ☐ 사본 없음 ☐ 법적 예외 기록 |
| 자료 소유자·제공자 역할 | 사람 이름 대신 역할과 권한 관계 |
| 수령/보관 책임자 역할 | 실제 접근 권한을 가진 역할 |
| 목적·허용 작업 | 구체적인 검수·변환 목적과 승인된 범위 |
| 권리·동의 근거 참조 | 원본 제공·변환·평문 결과 제공 권한의 비공개 증거 ID와 적용 범위 |
| 사본 생성/수령 시각 | 날짜·시각·시간대, 또는 해당 없음 |
| 보관 위치 유형 | 통제된 로컬 위치의 유형만. 실제 경로는 비공개 기록에만 |
| 접근 가능 역할 | 실제 접근 가능한 역할과 최소 권한 검토 |
| 사본 대상 범위 | source/result, 승인된 시트·열 범위의 비공개 참조 |
| 보유 만료 시각 | 내부 임시 사본은 승인된 기본 정책의 최대 7일 및 목적 조기 완료 중 이른 시각. 법적 예외는 별도 행 |
| 예정 조치 | ☐ 수동 삭제 ☐ 소유자에게 반환 ☐ 승인된 보존 예외 검토 ☐ 사본 없음·조치 불필요 |
| 조치 권한자 역할 | 삭제·반환 여부를 결정할 권한이 확인된 역할 |
| 조치 기한·상태 | 예정 기한 / ☐ 미착수 ☐ 검토 중 ☐ 완료 ☐ 보류 |
| 완료 증거 참조 | 반환 수령 또는 파기 확인을 뒷받침하는 비공개 기록 참조. 실제 증거가 없으면 미완료로 표시 |
| 예외·보류 사유 | 필요한 경우 최소한의 비공개 설명과 재검토 기한 |

### 운영자 원본 사본과 결과 사본 분리

원본 파일을 운영자가 별도 보관한 경우 운영자 원본 사본 한 행을 작성한다. 운영자가 생성한 HTML/ZIP/영수증을 별도 보관한 경우 운영자 결과 사본 행을 따로 작성한다. 고객이 통제하는 원본과 고객에게 전달된 결과물은 운영자 사본으로 기록하지 않는다. 고객 측 보유·삭제는 고객별 통지 및 합의 대상이며 이 도구가 확인하거나 대신 삭제하지 않는다.

### 사본이 없는 경우

파일을 받지 않았고 운영자가 원본이나 결과 사본을 만들거나 보관하지 않았다면 사본 없음을 선택한다. 사본 생성/수령 시각·위치·접근자·만료·삭제/반환 조치는 해당 없음으로 기록하고, 실제 비수령·비보유 확인의 비공개 증거 참조와 책임자 역할을 남긴다. 이 기록은 자료를 수신·검사하지 않았다는 증거 없이 작성하지 않는다.

### 법적 보존 예외

법적 보존 예외를 주장하는 경우 원본/결과 사본의 일반 보유 기록과 별도 행으로 분리한다. 근거 유형, 범위, 권한 있는 검토자 역할, 시작·만료 또는 재검토일, 보존 필요성을 입증할 비공개 참조를 기록한다. 서식은 예외의 적법성을 판정하지 않는다. 근거·권한·기한이 확인되지 않으면 자동으로 보존을 허용하지 말고 HOLD로 둔다.

## 2. 작성 전후 확인

- [ ] 실제 자료를 받거나 복사하기 전에 자료 소유자와 제공자 역할 및 구체적 사용·변환·결과 제공 권한을 확인했다.
- [ ] source와 result 사본의 소유·보관 책임자·위치 유형·접근 역할·만료 시각을 각각 기록했다.
- [ ] 승인된 기본 내부 임시 사본 보유기한(최대 7일)과 목적 조기 완료 시점을 고객 자료의 법정 보존기한으로 오인하지 않았다.
- [ ] 삭제 또는 반환 권한자·대상·시각·증거를 확인했다. 권한이나 법적 예외가 미확정이면 수동 조치도 HOLD로 두었다.
- [ ] 사본이 없으면 사본 없음을 명시하고 고객 원본을 임의로 삭제하거나 이동하지 않았다.
- [ ] 완료된 기록과 고객·권리자 증빙을 저장소에 넣지 않고, 접근 통제된 비공개 위치에 보관했다.

**한계:** 정책 승인은 합성 자료 시험과 내부 운영 기준에 한정된다. 이 빈 서식은 고객 보유·수령·파기 완료를 증명하지 않고 실제 R25의 필수 증거를 대신하지 않는다.
