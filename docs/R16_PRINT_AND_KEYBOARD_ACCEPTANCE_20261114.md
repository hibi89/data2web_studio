# DATA2WEB Studio — 최종설계 R16 A4·한국어 인쇄·키보드 실브라우저 검증 · 2026-11-14 KST

## 목표와 경계
- **전체 최종설계 100% 정본은 R01–R33 전부.** 이번 실개발은 R16(세 테마·제목/메타·한국어 인쇄) 및 R15(키보드 접근성)의 기존 부분 검증을 보강했다. 이 문서가 공식 85% 달성 또는 판매 승인을 의미하지 않는다.
- 첫 실행 CSS print media 에서는 표 영역이 넘칠 수 있었고 출력 PDF의 페이지·내용 검증은 없었다. 현재는 **A4 @page 13mm, 화면 검색/페이지 컨트롤 숨김, 인쇄 표 너비/줄바꿈·반복 헤더, 행 중간 잘림 완화**를 구현했다. 표의 범위는 사용자가 현재 선택한 **최대 50행/페이지**이며 전 131행을 인쇄한다고 오해하지 않게 현재 페이지/전체 건수 주석을 표시한다. 고객 데이터/기존 파일을 삭제·변조하지 않는다.
- 목록 행은 기존 Enter에 더해 **Space 키로 상세 정보 열기**, 프로그램이 내용을 사용한 행별 상세 설명 `aria-label`과 표 `aria-label`을 제공한다. 출력물 인쇄 시에는 화면에서 이전에 선택한 상세 영역을 숨겨 현재 페이지와 섞이지 않도록 한다.
