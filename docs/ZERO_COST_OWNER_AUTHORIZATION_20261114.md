# DATA2WEB Studio — 0원 운영·개발 경로 확정 (2026-11-14 KST)

## 승인 범위와 우선순위
사용자는 이번 채팅에서 **추가 현금지출이 없는 기본 정책·판단을 일괄 승인**하고 A 오프라인 HTML/ZIP/receipt 결과물 납품 전략 및 개발 구현 판단을 위임했다. 지출 상한은 **0원**, 예외·유료 전환은 자동 금지. 금전 지출과 **판매 대금**은 구별한다. 내부 SKU 표시가 BASIC 49,000원 / PRO 129,000원 / BUSINESS 249,000원, 각 범위·지원/환불은 기존 `docs/COMMERCIAL_OPERATION_POLICY_DRAFT_20261114.md` 초안을 **운영 기본안으로 승인**한 것이며, 실제 크몽 상품 등록/판매·플랫폼 수수료 또는 세무 적합성 증명은 아니다. 현재 RELEASE HOLD/SALE NO-GO.

승인 효력: (1) 무료 개발·테스트·CI (2) 상기 내부 SKU 정책 초안의 소유자 선택 (3) 고객 미수신/데이터 최소화와 수동 삭제 운영방침 (4) 공개 소스와 합성 fixture만 이용한 무료 정적 분석 준비. **반드시 별도 실제 증거가 필요한 항목**: 저작권자·제3자 라이선스/NOTICE, 고객별 사용권/개인정보 동의, 외부 독립 감사·실제 고객 인수, 법률/크몽 적합성. 소유자의 운영정책 승인은 타인의 저작권이나 고객 동의를 대신하지 않는다.

## 두 가지 0원 경로 비교 및 선택

| 선택지 | 현금지출 | 품질·수용 가능성 | 유지관리 | 결론 |
|---|---:|---|---|---|
| **A 결과물 납품 + 기존 CI + GitHub 공개 소스 CodeQL + 무료 외부 검토자 모집** | **0원** (공개 저장소 표준 runner) | 기존 hosted E2E 재사용, 보안 경고 탐지. 무료 사람 검토는 미확정이므로 R29 점수 0 | 간단 | **선택** |
| B native EXE 먼저 판매 + 무료 자체테스트 | 인증서 구매 0원일 수 있음 | 서명·실기기·지원/권리/신뢰 위험, R30/32 미충족 | 복잡 | 후순위 |

무료 CodeQL 기능은 **공개 GitHub 저장소**에서만 이 구성의 무상성을 전제한다. 저장소를 private으로 바꾸거나 larger runner/유료 Security 제품을 활성화하면 지출·접근조건 재확인 전 **중단**. GitHub Actions의 기본 표준 runner만 사용하고 예약/매일 과도한 실행 없이 feature 브랜치 push에서만 스캔. 근거: https://docs.github.com/en/actions/concepts/billing-and-usage 및 https://docs.github.com/en/code-security/getting-started/github-security-features

## 확정 데이터 취급 정책
- 기본은 **비개인정보·비민감·권리가 명시 확인된 표형자료만** 견적/수주 대상. 고객별 소유·적법한 처리권한/전달 경로는 주문마다 별도 확인하고 증빙 없이 실제 자료를 받지 않음.
- 먼저 **합성/익명 스키마**로 시험. 고객 실자료는 GitHub, ChatGPT, AI 에이전트, CodeQL workflow/로그/공개 이슈로 업로드 금지. 검수된 실제 데이터는 허용된 로컬 업무 경계에서만 다룬다. 고객이 사용하는 크몽의 파일 전달 기능을 거치게 되면 그 전송·보관은 별도 고지가 필요하다.
- 고객이 승인하여 로컬 임시 복제본을 처리한 경우 **인수확인 후 불필요한 사본은 최대 7일 이내** 법정 보존 예외를 제외하고 **권한자가 수동으로 파기·기록**. 고객 PC 원본·기존 산출물은 어떤 경우에도 자동삭제하지 않음. 실제 실행·파기증거 없이는 완료로 기록 금지.
- HTML/ZIP에는 평문이 포함될 수 있음. 고객은 비독점 내부 이용(권리 확인된 자산에 한함)만 기본 사용범위로 하고 빌더 소스/EXE/제3자 자산에 대한 소유권·재판매권은 허락하지 않는다. 실제 계약 전 고지·고객 동의를 확인.
- 수정/지원은 BASIC 1회/7일, PRO 2회/14일, BUSINESS 3회/30일. 환불은 관련 법령과 플랫폼 정책을 우선하고 **일괄 환불 불가** 금지. 미확인 플랫폼 수수료·세금은 매출/비용이 발생하기 전 별도 확인.
- `data/zero_cost_owner_policy_v1.json`과 `zero_cost_gate.py`가 내부 무상 기본값·미승인 판매·허위 R29 인증/점수 변조 방지를 회귀 검증. 이 검증기는 구매를 기술적으로 전역 차단하는 결제 방화벽은 아니므로 작업자가 유료 서비스를 수동 호출해서는 안 됨.

## 무료 감사의 증거 구분
1. 내부 합성 보안 preaudit + 무료 CodeQL은 개발자·자동화 **자가 보강**이다. 테스트 CI/CodeQL 성공은 **독립 보안감사 완료가 아니다**.
2. 독립 외부 감사 R29 수용은 별도의 실제 독립 검토자가 공개 코드/합성 입력으로 수행하고 대상 SHA·환경·결함/재현/수정 후 재평가 결과를 제공해야 한다. 공개 코드와 합성 fixture만 공유, 고객자료·비공개 비밀 전송 0, **검토자 무료 참여 가능 여부 미확정**.
3. 무료 외부 검토자가 없으면 R29는 PENDING 유지한다. 그 사이 R06·R07·R21·R25·R26·R27 등 각 요구의 실제 증거를 확보하는 대체 경로를 추진하되 실 고객/OS 검증이 없으면 수용점수 미추가.
4. `blueprint_score.py`는 기존 최종설계 R01–R33 **100점**, 현 **72점/85 목표13점 부족** 유지. 승인/문서/CI 때문에 임의 가산 금지.
