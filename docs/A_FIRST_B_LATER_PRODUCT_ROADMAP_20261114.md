# DATA2WEB Studio — A 우선 납품·B 후속 EXE 의사결정 및 전체 개발 로드맵

**결정:** 2026-11-14 KST 사용자는 기존 최종설계 R01–R33과 실제 검증을 근거로 **A 오프라인 결과물 납품형 우선, B 독립 Windows EXE 판매는 후속** 전략을 승인하고, 후속 개발까지 GitHub에 기록할 것을 지시했다. **기존 최종설계의 기술구현 방식 B(독립 stdlib 파서)와 이번 상품화 A는 서로 다른 비교축**이다. `docs/FINAL_DESIGN.md`와 `REQUIREMENTS.md`의 필수 범위·배점을 줄이지 않는다.

## 목적·수익화·가치
- 고객에게 고객 자신이 합법적으로 사용·제공할 수 있는 CSV·TSV·평면 JSON·XLSX의 **오프라인 읽기형 HTML 웹앱 + 결정적 ZIP + 영수증** 제공. 사용자 계정, 서버/유료API, 고객 원본 무단 업로드·자동 클라우드 전송, 사이트 분석, DB JOIN은 **초기 상품 범위 밖**.
- 판매자 측에서 검수하고 필요 시 로컬 빌더/GUI/미서명 EXE로 생성한다. **고객은 결과 HTML을 브라우저로 열며 EXE가 필요 없다.** 고객 원본이 개인/민감자료면 기본 HOLD. 출력에 데이터 원문이 **평문으로 포함되는 위험**을 선고지한다.
- 가격은 [기존 운영 초안](COMMERCIAL_OPERATION_POLICY_DRAFT_20261114.md)의 BASIC 49,000 / PRO 129,000 / BUSINESS 249,000원 **제안가**다. 실제 SKU 범위(상한/수정/지원), 플랫폼 수수료·사업/세무 조건·지원/환불에 대한 **최종 사용자 승인 전 상품 게시 금지**.

## A/B 제품 포트폴리오 — 둘 다 보존하되 순차 추진

| 고객 설치·유지 | 브라우저로 열기; 원본 업데이트는 계약 범위로 제한 | Windows 10/11·Python/Tcl/Tk bundle·드라이버/AV/서명·환불/고객지원 증가 |
| 비용·리스크 | 서버/API0, 개인정보 처리·IP·실고객/보안 감사 필요 | 위 요구 + 코드서명·재배포권·설치·업데이트/복구·Windows 버전 검증 |

## 고정 최종설계 72→85→95→100 로드맵
- 기준: R01–R33 **33개 총100점**, **22개 VERIFIED=72점**, **11개 PENDING=28점**, 현재 목표 85까지 **13점 부족**. 이는 **실제 실행증거를 통한 최종설계 점수**이고 제품 가격·매출/고객·출시 승인과 다름. 점수는 일부 확인·문서 작성·자가 점검만으로 가산하지 않는다.
- **M1: A 72→85, 필요한 정확한 5개=13점:** R07 (2: 승인된 자료권리·개인/공유 데이터 동의와 원본 불변), R21 (4: 권리자가 승인한 실제 사용허락/NOTICE를 포함하는 납품 계약), R25 (2: 원본 보존·보관기간/파기 책임 사용자 확정), R26 (2: 개인·민감정보 범위, 권한/평문 확인의 실제 동의 증거), R29 (3: **외부 독립 보안검증** XSS/CSP/경로경합·ZIP·XLSX 및 고객 OS/고급 TOCTOU 범위의 서명된 평가·취약점 재검증). 전부 완전 수용해야만 85; 서류 초안만으로 전혀 상승하지 않는다.
- **M2: A 운영고도화 85→95 (가정상):** R23 (3: 실제 Win10/11+macOS/Linux 고객 독립 실기기 브라우저), R27 (2: 확정 SKU/수정/지원/환불·크몽 운영), R30 (2: 독립 사용자 E2E·패키징/서명/권리 점검), R32 (3: 실고객 설치/실행/지원 및 재현 빌드·서명 등). 총10점이며 **각 요구 전체의 실증이 있을 경우**에만 95.
- **M3: 95→100 (가정상):** R06 (2: 원본 경합/TOCTOU 실OS·독립 시험), R33 (3: 상업 IP·실고객 수용/구매·환불·재배포 승인). 총5점; 변경된 계획이 실제 계약·권리를 대체하지 않는다.
- **병렬 실행:** 매 단계 개발자는 안전 자동화/합성 회귀·라이선스 인벤토리·정적 고객문서를 개선할 수 있다. CI 대기 중 독립 문서·악성 입력 회귀를 수행하되 **이익 미확정으로 점수 올리지 않는다**.
- **기계검증** [로드맵 JSON](../data/a_first_b_later_roadmap_v1.json) / `test_strategy_roadmap.py`는 기존 scorecard 상태/100점/72점/85/95/100 산술·미승인 판매/업로드/유료감사 차단을 확인한다. `python -m unittest test_strategy_roadmap -v`. 통과는 정책 파일 정합성이지 85점 달성 증거가 아니다.

## 고객 데이터·자동화 경계
- 수신 전에는 **형식·예시 헤더·예상 행/열·업무 목적**만 확인하고 실제 이름·이메일·주민번호·계약처·의료/결제자료를 요구하지 않는다. 합성·가명 예제 우선. 고객이 자체 컴퓨터에서 작업하는 방법 우선 제공.
- 법적 원본 사용권/제3자 제공·저장/파기 주체·경로를 계약에서 따로 확정하기 전 판매자 PC로 실제 원본을 받거나 원격 전송하지 않는다. HTML·ZIP은 데이터가 평문인 사실을 계약에 고지한다.
- **원본·기존 산출물은 자동 삭제·덮어쓰기 금지**. 작업용 결과는 새 create-only 폴더. 해시/영수증은 내용 진위/법률적 동의/암호학적 서명 인증이 아님.
- 크몽 주문·등록·고객통신의 자동 발신/결제·무료 공개 배포/고객자료의 클라우드 업로드는 **승인 전 하지 않는다**. 실제 게시되면 크몽 중앙 등록목록을 지우지 않고 `등록완료`로 표시하여 이력 보존.
